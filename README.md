# shlendle
An injection based Minecraft resizing, repositioning, mirroring and overlay utility for all Linux systems written in Rust

> [!IMPORTANT]  
> shlendle is **not** yet **legal** for use in MCSR Ranked nor speedrun.com: **use at your own risk**  
> shlendle is currently in **early development**, expect tons of **bugs**
